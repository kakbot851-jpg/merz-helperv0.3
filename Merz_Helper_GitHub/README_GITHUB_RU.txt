MERZ HELPER — СБОРКА EXE ЧЕРЕЗ GITHUB ACTIONS

Этот проект собирается на виртуальном Windows-компьютере GitHub Actions.
После успешной сборки GitHub даст скачать архив Merz-Helper-Windows.zip,
внутри которого будет Merz Helper.exe. Python на вашем компьютере не нужен.

КАК ПОЛУЧИТЬ EXE
1. Войдите на github.com или создайте бесплатный аккаунт.
2. Нажмите New repository. Назовите репозиторий, например merz-helper.
   Можно выбрать Private, если хотите скрытый репозиторий.
3. Распакуйте этот ZIP на компьютере.
4. Загрузите ВСЕ файлы и папки из распакованной папки в корень репозитория.
   Важно: папка .github вместе с workflows должна попасть в репозиторий.
5. Откройте вкладку Actions в репозитории.
6. Если GitHub попросит разрешить Actions, нажмите разрешение.
7. Откройте запуск "Build Merz Helper for Windows" и дождитесь зелёной галочки.
8. Внизу страницы запуска найдите Artifacts и скачайте Merz-Helper-Windows.
9. Распакуйте скачанный архив и запустите Merz Helper.exe.

Если автоматическая сборка не началась:
Actions → Build Merz Helper for Windows → Run workflow → Run workflow.

ПРИМЕЧАНИЯ
- GitHub Actions соберёт Windows EXE; Python на вашем ПК не требуется.
- Артефакт GitHub Actions хранится 30 дней. После изменения кода сборку можно
  запустить снова, чтобы получить новый EXE.
- Windows SmartScreen может предупредить о неизвестном издателе — это обычно
  бывает у самостоятельно собранных программ без цифровой подписи.
- Не публикуйте в репозитории реальные базы телефонных номеров или личные данные.
